# Hand Mouse — управление курсором жестами руки

Приложение отслеживает руку через веб-камеру и управляет курсором мыши.

## Как пользоваться

1. Запустите **«Запуск Hand Mouse.bat»** (двойной клик) — откроется окно предпросмотра с камерой.
2. Покажите камере жест **«палец вверх»** (указательный вытянут, остальные сжаты):
   - курсор **привязывается** к основанию указательного пальца и двигается за ним;
   - привязка держится, пока рука в кадре (можно менять жесты);
   - рука пропала из виду → **привязка сбрасывается**, курсор замирает;
   - снова показали жест → курсор снова привязывается.
   - Курсор управляется **основанием пальца (сустав у ладони)**, поэтому при щипке
     курсор не прыгает, а перетаскивание работает.
3. **Открытая ладонь** (все 5 пальцев прямые, удержать ~0.2 сек) → **отмена привязки**,
   курсор замирает. Это удобный «выключатель» управления.
4. Пока курсор привязан, работает **щипок** (сжать большой + указательный) = нажатие мыши:
   - короткий щипок → **клик**;
   - щипок с удержанием и движением → **перетаскивание** (drag & drop).
5. **ESC** или закрытие окна — выход.

## Полезно знать

- Статус в окне предпросмотра: **FREE** (оранжевый) — привязки нет, **BOUND** — курсор
  следует за пальцем, **PINCH** — щипок зажат.
- Линия между большим и указательным пальцем в окне подсказывает состояние:
  серая — далеко, жёлтая — рядом, **зелёная — клик**.
- Сглаживание курсора включено (чтобы не дрожал). Если курсор кажется «медленным»,
  уменьшите `SMOOTHING` в файле `hand_mouse.py` (0 = мгновенно за пальцем).

## Настройки (в начале файла hand_mouse.py)

| Параметр          | По умолчанию | Что делает                                             |
|-------------------|--------------|--------------------------------------------------------|
| `MARGIN_X/Y`      | 0.15         | Отступ рабочей зоны по краям кадра                     |
| `SMOOTHING`       | 0.45         | Плавность курсора (меньше = резче)                     |
| `PINCH_ON`/`PINCH_OFF` | 0.38/0.55 | Пороги срабатывания щипка (гистерезис от дрожания)  |
| `DRAW_LANDMARKS`  | True         | Показывать скелет руки в окне предпросмотра            |

## Требования

- Windows, Python 3.12 (установлен), веб-камера.
- Библиотеки: opencv-python, mediapipe, pyautogui (уже установлены).
- Модель `hand_landmarker.task` лежит рядом со скриптом.

## Файлы

- `hand_mouse.py` — само приложение.
- `Запуск Hand Mouse.bat` — удобный запуск.
- `hand_landmarker.task` — модель распознавания руки (MediaPipe).
